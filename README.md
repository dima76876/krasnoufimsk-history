# Красноуфимск: Сквозь эпохи

**Интерактивный историко-экскурсионный путеводитель по Красноуфимску.**

Проект объединяет историю города, достопримечательности и готовые маршруты. Он помогает познакомиться с Красноуфимском и спланировать путешествие.

🌐 [Открыть сайт](https://krasnoufimsk-history.site/) · 🧭 [Планировщик путешествия](https://krasnoufimsk-history.site/planner.html)

## Что есть на сайте

- **История города** — хронология из 21 вехи.
- **Достопримечательности** — 27 мест с описаниями, адресами и расположением на карте.
- **Интерактивная карта** — достопримечательности и три экскурсионных маршрута.
- **Викторина** — 46 вопросов о городе и его истории, паспорт путешественника и памятный диплом.
- **Памятка туриста** — полезная информация с возможностью сохранить её в PDF.
- **Планировщик путешествия** — программа поездки с учётом города отправления, даты и других параметров.

Сайт доступен на русском и английском языках. В нём предусмотрены светлая и тёмная темы, сезонное оформление и режим для слабовидящих.

## Работа без интернета

Сайт поддерживает установку как PWA. После посещения и загрузки основных материалов страницы и карта могут работать без подключения к интернету. Для получения свежего прогноза погоды и поиска новых городов необходимо соединение.

## Технологии

Проект создан с использованием HTML, CSS и JavaScript. Для карты используются Leaflet, PMTiles и данные OpenStreetMap; для создания PDF — pdfMake. Шрифты и основные библиотеки находятся в составе проекта.

## Источники

Источники исторических сведений и материалов доступны на сайте: ссылка на них находится внизу главной страницы.
