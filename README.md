## 📖 О проекте
«Красноуфимск: Живая история» — это интерактивный цифровой краеведческий веб-путеводитель, объединяющий глубокое историко-архивное исследование 290-летней летописи города с передовыми веб-технологиями нативного стека (SPA без использования тяжелых фреймворков).

Ресурс создан как практико-ориентированный инструмент для популяризации культурно-исторического наследия Урала среди молодёжи, школьников, жителей и туристов города Красноуфимска. Вся информация, адреса и списки достопримечательностей прошли фактчекинг и очистку от недостоверных данных, опираясь на официальные реестры.

## ✨ Ключевые возможности веб-путеводителя

* 📜 **Интерактивная летопись:** 11 ключевых этапов (1736–2026), от закладки деревянной крепости воеводой Петром Бахметевым до современной набережной 2026 года.
* 🎓 **Продвинутая краеведческая викторина с сертификатами:**
  - База из более чем 45 вопросов.
  - 3 уровня сложности (Лёгкий, Средний, Сложный).
  - Алгоритм защиты от угадывания (перемешивание вариантов ответов в реальном времени).
  - Автоматическая генерация именного сертификата «Знатока Красноуфимска» через **HTML5 Canvas** (доступен для скачивания в формате PNG на ПК и смартфонах).
* 🗺️ **Интерактивные карты и маршруты (Яндекс.Карты):**
  - Подробный реестр памятников архитектуры с подтверждёнными реальными адресами.
  - 3 авторских пешеходных маршрута («Историческое ядро», «Панорама и Красный Яр», «Железнодорожный щит») с кнопками мгновенного построения пути в приложении навигатора.
* 🎨 **Динамический дизайн и Glassmorphism:**
  - Умный алгоритм окрашивает сайт в одну из 4 сезонных палитр в зависимости от текущего месяца.
  - Анимированные частицы на Canvas (снежинки, искры, лепестки, листья), меняющиеся вместе с сезоном.
  - Переключатель Тёмной/Светлой темы с плавными переходами.
* 🌡️ **Живой погодный информер (API MET Norway):** получение точной температуры воздуха и погодных условий от Метеорологического института Норвегии без ключей. Интегрирована система умного кэширования для оффлайн-работы.
* 🌐 **Двуязычный интерфейс (RU / EN):** мгновенный перевод всех текстов, летописи, карточек и викторины без перезагрузки (на базе словаря `i18n`).
* 📱 **Mobile-First Эргономика & UX:** аппаратный плавный скролл на iOS, защита от прокрутки фона при открытых окнах, блокировка синих вспышек при тапе, а также адаптивная сетка под любые смартфоны.
* 🛡️ **Защита от AdBlock:** скрипты Яндекс.Карт обернуты в защитные блоки, предотвращающие падение сайта при агрессивной блокировке трекеров.

## 🛠️ Архитектура и технологии

| Направление | Стек технологий | Особенности реализации |
|---|---|---|
| **Разметка** | HTML5 Semantic | Семантические теги, доступность (ARIA, `data-i18n`). Вся структура собрана в едином SPA-документе. |
| **Стилизация** | CSS3 Modern | CSS Variables, Flexbox, CSS Grid, Glassmorphism (`backdrop-filter`), сложные медиа-запросы `@media`, адаптивность под iOS/Android. |
| **Логика** | JavaScript (ES6+) | Нативный Vanilla JS (более 1500 строк), Fetch API, Canvas 2D API (генерация графики и сертификатов на лету), LocalStorage. |
| **Интеграции** | Яндекс.Карты URL Scheme, MET Norway API | Динамическое формирование навигационных ссылок (lat, lon) и асинхронные запросы данных о погоде. |
| **Хостинг** | GitHub Pages CDN | Нулевая себестоимость, быстрый отклик по всему миру. |
