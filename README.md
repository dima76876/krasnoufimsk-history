## Что на сайте

- Хроника из **21 вехи** истории Красноуфимска с навигацией по годам.
- Каталог из **27 мест** с описаниями, адресами, координатами, историческими фактами и кнопкой построения внешнего маршрута. По решению владельца карточки объектов оформлены без фотографий.
- Интерактивная карта Leaflet на локальном векторном PMTiles-пакете Protomaps/OpenStreetMap для территории всех 27 объектов, три туристических маршрута, викторина из **46 вопросов** в трёх режимах, погода met.no с резервным Open-Meteo, памятка туриста, генерация PDF-гида и памятного диплома JPEG.
- RU/EN-интерфейс: **212 ключей** на главной странице и **91 ключ** в планировщике.
- Светлая и тёмная темы, сезонное оформление (**при первом заходе — «Авто» по календарю**), режим для слабовидящих, поддержка `prefers-reduced-motion`, клавиатурная навигация и PWA с Service Worker **v32**.
- Inter и Playfair Display, Leaflet 1.9.4, Protomaps/PMTiles и pdfMake 0.2.7 лежат локально, поэтому шрифты, карта и PDF не зависят от CDN. Внешними остаются только запросы свежей погоды и первичного геокодинга; последний успешный прогноз и уже найденные города повторно используются офлайн.

## Планировщик путешествий

`planner.html` составляет рекомендуемые программы на **1–14 дней** для **1–20 человек** по объектам и маршрутам Красноуфимска.

Расстояния для встроенного списка городов сверены как дорожные оценки по OSRM 18 октября 2026 года. Для произвольного населённого пункта используется геокодинг Open-Meteo и только приближённая оценка автомобильной дороги; прямые поезда, автобусы, авиарейсы и тарифы не выдумываются. Успешные геокодинг-запросы кэшируются до 40 последних вариантов на 90 дней, поэтому уже найденный город можно выбрать и без сети. Время, цены и расписания нужно проверять у перевозчика на дату поездки.

## Данные и ограничения

Исторические даты, адреса и координаты объектов сверены с источниками по состоянию на октябрь 2026 года; точки на карте выставлены по адресам и данным OpenStreetMap. Для одиннадцати объектов в карточках указаны реестровые номера; перед официальным использованием актуальность, категорию и границы охраны нужно сверять с ЕГРОКН.

Статус благоустройства набережной «Красный Яр» приведён по публикации KSK66 от 16.10.2026: работы на нижнем уровне продолжаются, поэтому доступность участков следует уточнять перед посещением.

Сайт выполнен в ходе индивидуального проекта. Источники и кредиты открываются из подвала главной страницы в модальном окне.

## Локальный запуск

Сайт не требует сборки. Достаточно распаковать папку и открыть `index.html` в браузере. Для полноценной проверки PWA и офлайн-режима нужен локальный HTTP-сервер, например:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

## Публикация на GitHub Pages

Загружать нужно **содержимое** папки проекта в **корень репозитория**, а не папку целиком: в корне репозитория должны лежать `index.html`, `planner.html`, `sw.js`, `CNAME` и папки `assets/`, `vendor/`, `images/`, `.github/`.

1. Открыть репозиторий → **Add file → Upload files**.
2. Перетащить все файлы и папки из распакованного архива (веб-загрузка GitHub принимает не более 100 файлов за раз — в проекте их меньше).
3. Убедиться, что папка проекта не вложена сама в себя: путь должен быть `index.html`, а не `krasnoufimsk-history/index.html`.
4. **Commit changes**. GitHub Pages подхватывает корень ветки; файл `CNAME` (`krasnoufimsk-history.site`) обязателен, иначе отключится пользовательский домен.

Файл `_headers` хранит security-заголовки для хостингов, которые используют этот формат (Netlify и совместимые CDN). На чистом GitHub Pages custom-заголовки недоступны — для них нужен CDN/прокси, например Cloudflare.

## Офлайн-режим и локальное открытие

После первого открытия опубликованного сайта по HTTP/HTTPS Service Worker v32 сохраняет страницы, CSS/JS, локальные шрифты, изображения, vendor-библиотеки и `assets/maps/krasnoufimsk.pmtiles`. Запросы PMTiles с HTTP Range Service Worker обслуживает из полного локального архива ответами 206, поэтому карта всей территории работает офлайн, а не только просмотренные участки. Свежую погоду без сети получить нельзя: сайт показывает последний сохранённый прогноз с датой обновления и только при его отсутствии — сезонный базовый расчёт.

Распакованный архив также можно открывать прямо из папки через `file://`: ссылки страницы 404 в этом режиме становятся относительными, а карта лениво подгружает script-based копию того же PMTiles-архива (`krasnoufimsk.pmtiles.base64.js`), поскольку Chromium блокирует `fetch()` к соседнему бинарному файлу на `file://`. Service Worker на `file://` браузерами не запускается — это ограничение протокола, а не сайта.
