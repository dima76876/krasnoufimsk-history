# Красноуфимск: Сквозь эпохи

Цифровой историко-экскурсионный комплект о Красноуфимске Свердловской области: интерактивный путеводитель и планировщик поездки. Сайт выполнен в ходе индивидуального проекта.

- Сайт: <https://krasnoufimsk-history.site/>
- Планировщик: <https://krasnoufimsk-history.site/planner.html>
- Репозиторий: <https://github.com/dima76876/krasnoufimsk-history>

## Возможности

- Хронология с 21 вехой истории города.
- 27 достопримечательностей с описаниями, адресами и расположением на карте.
- Интерактивная карта и три экскурсионных маршрута.
- Викторина из 46 вопросов с разными уровнями сложности, паспорт путешественника и памятный диплом в формате JPG.
- Памятка туриста, которую можно сохранить в PDF.
- Планировщик путешествия с выбором города отправления, даты и параметров поездки.
- Русский и английский языки, светлая и тёмная темы, сезонное оформление и режим для слабовидящих.
- Поддержка установки как PWA и работы основных материалов без интернета после загрузки.

Карточки достопримечательностей оформлены без фотографий. Источники открываются по ссылке внизу главной страницы.

## Планировщик путешествия

Планировщик помогает составить программу на 1–14 дней для 1–20 человек. Перейти к нему можно с главной страницы через меню или по прямой ссылке.

Для встроенных городов используются дорожные оценки; для произвольного населённого пункта — геокодинг и приблизительная оценка расстояния. Расписания, стоимость билетов и доступность транспорта необходимо уточнять у перевозчиков на дату поездки. Результаты успешных запросов городов сохраняются для повторного использования.

## Офлайн-режим

При посещении сайта по HTTPS Service Worker сохраняет основные страницы, стили, скрипты, шрифты, библиотеки, изображения и локальный пакет карты. После успешного сохранения эти материалы доступны без сети. Для первого посещения и загрузки ресурсов нужен интернет; для свежего прогноза погоды и поиска новых городов также требуется соединение. Доступность кэша зависит от настроек браузера и свободного места.

Карта использует локальный архив PMTiles с данными OpenStreetMap. При открытии сайта непосредственно из папки через `file://` карта может загрузить локальную script-копию архива. Service Worker при таком открытии не работает; для проверки PWA нужен HTTPS или локальный сервер на `localhost`.

## Публикация на GitHub Pages

Файлы проекта размещаются в корне репозитория: рядом с `index.html` находятся `planner.html`, `sw.js`, `CNAME` и папки `assets`, `vendor` и `images`.

Для замены отдельного файла через веб-интерфейс GitHub откройте соответствующую папку, выберите **Add file → Upload files**, загрузите файл с тем же именем и подтвердите **Commit changes**. При полной загрузке сохраняйте структуру папок. Файл `CNAME` содержит пользовательский домен сайта.

Файл `_headers` предназначен для хостингов, поддерживающих этот формат; сам по себе GitHub Pages пользовательские заголовки из него не применяет.

## Поисковые системы

Основные адреса страниц указаны в `sitemap.xml` и в тегах canonical. При ручном переключении языка к адресу может добавляться `?lang=ru` или `?lang=en`: такая ссылка сохраняет выбор языка. Канонические адреса при этом остаются без параметра. Решение об индексации и выборе адреса в поиске принимает поисковая система.

## Данные и изображения

Исторические сведения и адреса приведены по краеведческим и другим открытым источникам; перед поездкой стоит уточнять часы работы, доступность объектов и актуальность информации. Сведения об объектах культурного наследия для официального использования следует сверять с ЕГРОКН.

Сезонные фоновые изображения главной страницы находятся в `images/`: `unsplash.webp`, `bg_winter.webp`, `bg_spring.webp`, `bg_summer.webp`. Герб и служебные изображения также находятся в этой папке. Локально подключены шрифты, Leaflet, библиотеки карты и pdfMake; сведения о лицензиях сторонних библиотек находятся в проекте.
